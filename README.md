## About

Senior Full-Stack Engineer with **6+ years** building scalable, high-performance web applications in **React.js and Node.js**. Currently at **[GeekyAnts](https://geekyants.com)**, where I lead full-stack delivery across three concurrent ERP projects for a six-person team, and mentor the engineers on it.

I'm a daily practitioner of **AI-assisted development** — Claude, ChatGPT and Gemini for code generation, refactoring, debugging, test creation and review — with the important caveat that I validate and test everything rather than shipping AI output unreviewed.

```
Built an event-driven AWS pipeline from scratch — Lambda, SQS, S3, Step
Functions, Terraform — processing 3M records/day incrementally on a
10M-record base, with retry policies and CloudWatch alarms.

Solo-built an OCR microservice (Tesseract) for region-based text
extraction from large-format drawings up to 1GB, deployed as a
reusable AWS-hosted module.
```

Open to **collaboration, freelance, and mentorship** — [drop me a line](mailto:biswassrijeet99@gmail.com).
